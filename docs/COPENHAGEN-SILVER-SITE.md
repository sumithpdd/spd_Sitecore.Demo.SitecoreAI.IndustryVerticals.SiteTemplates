## Site purpose

**Sitecore Silver Celebration** is a marketing microsite for Sitecore’s 25th anniversary in-person event in Copenhagen (Tivoli, 11 June 2026). It is designed to:

1. **Promote the event** — hero, intro band, Tivoli CTA, and link to the official event registration page.
2. **Explain the SitecoreAI platform** — three engine promos (CMS, Agentic RAG, Data Platform) on Home, plus a dedicated **Capabilities** page with five capability cards.
3. **Showcase people and AI** — **Silver Attendees** section with attendee profiles (e.g. Sumith Damodaran) including AI-enhanced portrait and quote.
4. **Demonstrate Sitecore AI Pages** — authors use partial designs (header/footer), headless variants, presentation styles, and the shared **Promo** component for live demos.

**Audience:** prospects, customers, and internal teams at the Silver Celebration and follow-up demos.

**Design reference:** [copenhagen-silver.vercel.app](https://copenhagen-silver.vercel.app/) — dark silver theme, red CTAs, textured backgrounds.

## Inline editing in Pages / Experience Editor

All `SitecoreSilver*` components under `src/components/sitecoresilver/` bind content through **Content SDK field components** so authors can click and edit in Pages:

| Field type | React component | Import alias |
|------------|-----------------|--------------|
| Single-line / multi-line text | `<Text field={…} tag="span" />` | `Text as ContentSdkText` |
| Rich text | `<RichText field={…} />` | `RichText as ContentSdkRichText` |
| Image | `<NextImage field={…} />` | `NextImage as ContentSdkImage` |
| General link | `<Link field={…} className="…" />` | `Link as ContentSdkLink` |

**Fallback behavior:** When a field is empty, demo copy from `sitecoresilver-copenhagen-defaults.ts` renders only in **preview** (`!page.mode.isEditing`). In **editing mode**, the SDK field chrome is always shown so authors can populate empty fields.

**Do not** render authored copy as plain strings (`{textValue(fields.Title)}`) — that bypasses inline editing.

## Demo guide: Promo component (styles + variants)

The shared kit **Promo** component (`src/components/promo/Promo.tsx`, `componentName: Promo`) supports multi-variant layouts and presentation styles — same pattern as [Versele in SE9](C:\code\sitecore\SE9\examples\versele). Use it on Capabilities or any content page for authoring demos.

**Setup:** Add a **Promo** rendering to `headless-main`, datasource **Data/Promos/Demo Promo** (or create a new item under `Data/Promos/`).

### Part 1 — Styling (Default variant)

1. Collapse the left sidebar in Pages to focus on the right panel.
2. Select the **Promo** component.
3. In the right sidebar, expand **Styling**.
4. Under **Promo**, toggle styles and observe live preview:

| Style (CM) | CSS class | Effect on **Default** variant |
|------------|-----------|-------------------------------|
| Promo Accent Blue | `accent-blue` | Blue inset accent on the image edge |
| Promo Accent Orange | `accent-orange` | Orange inset accent |
| Promo Accent Pink | `accent-pink` | Pink inset accent |
| Promo Reversed | `promo-reversed` | Image moves to the right; accent flips to the opposite edge |

5. Uncheck styles to show the before/after difference.

### Part 2 — Rendering variant (WithColumns)

1. Expand **Advanced Styling** (or **Variant** / `FieldNames` depending on UI).
2. Select rendering variant **WithColumns**.
3. Explain: **WithColumns** uses a three-card column layout — there is **no accent box** behind the image, so **Promo Accent Blue/Orange/Pink have no visible effect**.
4. Apply **Promo Reversed** — image and columns swap sides (`flex-row-reverse`).
5. Return to **Styling**, uncheck accent classes, and compare.
6. **Content editing:** select the middle card text (Promo title/body fields) and delete or shorten copy to show inline editing.

### Part 3 — Other styles (optional)

| Style | CSS class | Layout |
|-------|-----------|--------|
| Promo hero | `promo-hero` | Card: image on top, text below |
| Promo overlay | `promo-overlay` | Text overlay on image |
| Button link style (Common) | `link-button` | Shows explicit CTA button |

**Implementation:** Styles resolve to `params.styles` on the root `<div class="component promo …">`. CSS: `src/assets/components/promo.css`. Serialized styles: `Presentation/Styles/Promo/`. Headless variants: `Presentation/Headless Variants/Promo/` (`Default`, `WithColumns`).

## Authoring checklist

1. **Push serialization** (renderings + Available Renderings + placeholder settings must be in CM):
   ```powershell
   dotnet sitecore cloud login
   dotnet sitecore cloud environment connect --environment-id 5Cph5EjHd57eURM3odbI7c --allow-write
   dotnet sitecore serialization push -n SitecoreSilverProd -i sitecoresilver
   ```
2. **Publish** — Presentation + Layout + templates under `/sitecore/templates/Project/sitecoresilver` and renderings under `/sitecore/layout/Renderings/Project/sitecoresilver`.
3. **Available Renderings** — Content Editor → `/sitecore/content/sitecoresilver/sitecoresilver/Presentation/Available Renderings/SitecoreSilver` → **Renderings** field must list all Copenhagen Json renderings (not empty).
4. **Placeholder settings** — Under `Presentation/Placeholder Settings/`: `headless-main`, `headless-header`, `headless-footer` must include **SitecoreSilver** in Allowed Controls (Pages toolbox).
5. **Header nav** — Open `SitecoreSilverEventHeader` → add **LinkList** under `sitecoresilver-header-nav-1`.
6. **Badge grid** — Add `SitecoreSilverPromoBadgeGrid` with `DynamicPlaceholderId=1` → three `SitecoreSilverPromoBadge` children.
7. **Rich text** — Select **GlassPanel** variant (`FieldNames=GlassPanel`); Headless Variants → `SitecoreSilverRichText`.
8. **Attendee profile** — New attendee pages use template **SitecoreSilverAttendeeProfile**; add profile component without a `Data/` datasource; edit fields on the page item.
9. **Capabilities** — `SitecoreSilverCapabilitiesSection` on `/Capabilities` with five **SitecoreSilverCapabilityCard** children in `sitecoresilver-capability-cards-1`.

### Troubleshooting: components not visible in Pages / EE

| Symptom | Cause | Fix |
|---------|--------|-----|
| Empty **SitecoreSilver** group in Available Renderings | Wrong field ID on push (fixed in repo) | Re-push; verify **Renderings** field on `Available Renderings/SitecoreSilver` |
