# Pinsent Masons brand tokens (Legal vertical)

Demo approximation of [pinsentmasons.com](https://www.pinsentmasons.com/) for the `legal` rendering host. Not an official brand pack. Tokens live in `src/assets/base/variables.css`. Layout classes: `src/assets/components/header-footer-legal.css`.

Do **not** use yellow. Maroon for logo, pill CTAs, and borders. Dark teal for section bands.

## Typography

| Item | Value |
|------|--------|
| Family | **Segoe UI** (fallbacks: `ui-sans-serif`, `system-ui`, sans-serif) |
| Headings / body | `--font-heading` / `--font-body` |

## Color tokens

| Token | Hex | Role |
|-------|-----|------|
| `--color-accent` / `--color-primary` | `#7C0A2E` | Maroon — logo, primary CTAs, button borders |
| `--color-accent-dark` | `#5C0722` | Maroon hover |
| `--color-accent-light` | `#A31240` | Maroon highlight |
| `--color-surface-teal` | `#005955` | Teal bands / success |
| `--color-surface-dark` | `#0D3D3C` | Dark teal section bands |
| `--color-foreground` | `#1E2326` | Charcoal body |
| `--color-background` | `#FFFFFF` | Page |
| `--color-background-accent` | `#F6F6F6` | Grey bands |
| `--color-border` | `#D9D9D9` | Rules |

`--radius-base` is pill-shaped (`9999px`) for primary buttons.
